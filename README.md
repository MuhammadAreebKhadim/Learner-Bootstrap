# 🎓 Learner - Online Courses Website

## 📌 Overview

**Learner** is a modern and responsive online courses landing page built using HTML, CSS, and Bootstrap.
It is designed to showcase courses, instructors, testimonials, and blog content in a clean and user-friendly interface.

This project is ideal for beginners who want to practice frontend development and build real-world UI designs.

---

## 🚀 Features

* ✅ Fully responsive design (mobile, tablet, desktop)
* 🎯 Modern UI/UX layout
* 📚 Featured courses section
* 👨‍🏫 Instructor profiles
* ⭐ Testimonials and ratings
* 📰 Blog section
* 📊 Statistics and call-to-action sections
* 🎨 Custom styling using CSS variables
* ⚡ Built with Bootstrap 5

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Bootstrap 5**
* **Bootstrap Icons**
* **Google Fonts (Roboto & Poppins)**
